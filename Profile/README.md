# Rift

Welcome to the official GitHub organization for **Rift**.

Rift is an all-in-one Discord bot designed to provide powerful moderation, utility, automation, and community management features. This organization contains the source code for the Rift ecosystem, including the Discord bot, dashboard, website, documentation, and supporting web services.

## Repository Overview

| Repository                                                 | Description                                                           |
| ---------------------------------------------------------- | --------------------------------------------------------------------- |
| **[Rift](https://github.com/Rift-devs/Rift)**              | The complete source code for the all-in-one Discord bot.              |
| **[Dashboard](https://github.com/Rift-devs/dash)**         | The web dashboard used to manage and configure Rift.                  |
| **[Website](https://github.com/Rift-devs/website)**        | The source code for the official Rift website.                        |
| **[Documentation](https://github.com/Rift-devs/Docs)**     | User guides, API documentation, and developer resources.              |
| **[Privacy Policy](https://github.com/Rift-devs/privacy)** | Source code for the Privacy Policy page hosted on the Rift website.   |
| **[Terms of Service](https://github.com/Rift-devs/tos)**   | Source code for the Terms of Service page hosted on the Rift website. |

## Security

Sensitive files such as `.env` files, API keys, authentication tokens, and other secrets are **never** committed to this organization.

If you discover a security vulnerability, please report it privately via email rather than creating a public issue.

## Contributions

This organization is **not** accepting external contributions at this time. Pull requests from outside contributors will generally not be reviewed or merged unless explicitly requested by the Rift development team.
